## 核心功能

- TXT、Markdown、PDF、DOCX 加载、清洗、父子分块；
- File/MySQL Repository、Chroma、BM25、NetworkX Graph 持久化与同步删除；
- Naive、Advanced、GraphRAG 和 Agent 自动路由；
- LangGraph Workflow、Branch、Loop；
- PASS、REGENERATE、REWRITE_RETRIEVE、CLARIFY、REFUSE；
- Query Rewrite 语义守恒、引用映射、execution trace、无答案拒答；
- LLM transport retry、答案异常拦截和确定性 Grounded Fallback；
- Streamlit 文档管理、模式选择、聊天、引用和执行轨迹展示。

## 架构与工程规范

项目使用 Python 3.12 src-layout。`bootstrap.build_application_services()` 是唯一生产 Composition
Root；UI 和 Agent 依赖抽象，不直接创建数据库、Chroma、Graph 或模型客户端。AST 架构测试保护
依赖方向，需求追踪矩阵把 FR/NFR 映射到实现与测试。CI 使用冻结依赖、Ruff、compileall、pytest
和独立 MySQL 8.4 合同 job。

## 从 v0.7.0 到 v1.0.0

- 将回答缺陷与检索缺陷分流，新增独立 regeneration/retrieval retry 预算；
- 阻止 Query Rewrite 增加新实体、品牌、资质或无关子问题；
- 阻止供应商能力幻觉、异常语义替换和父文档全文倾倒；
- 增加可恢复 LLM transport retry 和 Graph/流程类 deterministic fallback；
- 完善 citation 去重映射、execution trace、真实人工问题回归；
- 完成需求、边界、DI、TDD 事实、CI、部署、验收、发布和 Demo 文档闭环。

## 安装与启动

```powershell
uv sync --frozen
Copy-Item .env.example .env
uv run python scripts/check_environment.py
uv run streamlit run app.py
```

MySQL 初始化和全部环境变量见项目 README 与 `docs/deployment.md`。不得提交 `.env` 或真实密钥。

## 已知限制

- 目标为单机/课程演示规模，不提供生产级高并发、高可用或分布式部署；
- 不包含企业级多租户、认证/RBAC、审计、自动备份与灾备；
- 规则 Graph 抽取不等于商业知识图谱平台；
- Hash Embedding 适合离线测试，外部语义模型质量和可用性由服务商决定；
- 尚未覆盖复杂 OCR、跨页表格、浏览器级 E2E、负载基准和生产监控告警。
